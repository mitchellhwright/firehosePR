# Security

Do not include credentials or private source in public issues. Use GitHub's private vulnerability reporting when enabled, or contact the repository owner through a private channel.

Treat all candidate code, PR text, artifacts, and job logs as untrusted. A matching string, cached receipt, or successful historical run is not sufficient authority to skip a current obligation. Consumers must authenticate provenance and bind all inputs before reuse.

The portable CLI plans work; it has no GitHub mutation or deployment command. The historical controllers in `reference/` are not installed with the package and are not active workflows.
